# FOMO-X

Production-style event-driven Solana trading infrastructure, built solo over 7 days.

## Stack
- Frontend: Next.js + React + TypeScript
- Backend services: Go
- Social/API service: TypeScript + Fastify
- AI/Trader intelligence: Python + FastAPI
- Blockchain: Solana
- Streaming: Redpanda/Kafka
- OLTP: PostgreSQL
- Cache: Redis
- Analytics: ClickHouse
- Realtime: WebSockets
- Infrastructure: Docker Compose
- Testing: Go tests + Vitest + Pytest
- Observability: Prometheus + Grafana
- CI: GitHub Actions
